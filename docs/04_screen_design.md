## 1. 전체 화면 구성

### 1.1 레이아웃 구조

PMS의 기본 레이아웃은 **좌측 사이드바 + 상단 헤더 + 우측 메인 컨텐츠** 3단 구조로 구성된다.  
로그인 화면은 레이아웃 없이 단독 페이지로 표시된다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│  HEADER                                                                 │
│  [로고]  [프로젝트 선택 ▼]              [🔔 3]  [사용자명 ▼]           │
├──────────────┬──────────────────────────────────────────────────────────┤
│              │  Breadcrumb: 홈 > 프로젝트 > 업무관리                   │
│  SIDEBAR     ├──────────────────────────────────────────────────────────┤
│              │                                                          │
│  📊 대시보드  │                                                          │
│  📁 프로젝트  │              MAIN CONTENT AREA                          │
│  ✅ 업무     │                                                          │
│  📄 산출물   │                                                          │
│  ⚠️  이슈    │                                                          │
│  👥 인력     │                                                          │
│  🔔 알림     │                                                          │
│  ⚙️  시스템  │                                                          │
│              │                                                          │
└──────────────┴──────────────────────────────────────────────────────────┘
```

**레이아웃 사양**

| 영역 | 너비/높이 | 비고 |
|------|-----------|------|
| 헤더 | 높이 64px, 너비 100% | 고정(fixed), z-index: 100 |
| 사이드바 | 너비 240px (축소 시 64px) | 좌측 고정, 토글 가능 |
| 메인 컨텐츠 | 나머지 전체 | 스크롤 가능, padding: 24px |
| 브레드크럼 | 높이 40px | 메인 컨텐츠 상단 고정 |

## 2. 공통 컴포넌트

### 2.1 헤더 (AppHeader.vue)

```
┌─────────────────────────────────────────────────────────────────────────┐
│ [≡] [OKE PMS 로고]   [▼ 2024-스마트팩토리구축사업]        [🔔 5] [김철수 ▼] │
│                                                               ↑배지숫자   │
└─────────────────────────────────────────────────────────────────────────┘
```

**구성 요소**

| 요소 | 설명 | 비고 |
|------|------|------|
| 사이드바 토글 버튼 (≡) | 사이드바 펼침/접힘 | 좌측 고정 |
| 로고 | OKE PMS 텍스트 로고 또는 이미지 | 클릭 시 대시보드 이동 |
| 프로젝트 선택 드롭다운 | 접근 가능한 프로젝트 목록 표시 | 선택 시 해당 프로젝트 컨텍스트 전환 |
| 알림 아이콘 | 벨 아이콘 + 읽지 않은 알림 배지 | 빨간 원형 배지, 최대 99+ 표시 |
| 사용자 메뉴 | 사용자명 + 드롭다운 | 내 프로필, 비밀번호 변경, 로그아웃 |

**Props (AppHeader.vue)**
```typescript
interface Props {
  projects: ProjectSummary[]       // 접근 가능한 프로젝트 목록
  currentProjectId: string | null  // 현재 선택된 프로젝트
  unreadCount: number              // 읽지 않은 알림 수
  currentUser: UserInfo            // 로그인 사용자 정보
}
```

### SCR-001: 로그인

#### 3.1.1 화면 개요

| 항목 | 내용 |
|------|------|
| 화면 ID | SCR-001 |
| 화면명 | 로그인 |
| URL | `/login` |
| 접근 권한 | 비로그인 사용자 |
| 컴포넌트 | `views/auth/LoginView.vue` |

#### 3.1.2 기능 설명

- 이메일과 비밀번호를 입력하여 로그인
- 입력값 유효성 검사 (이메일 형식, 필수 입력)
- 로그인 실패 시 오류 메시지 표시
- 로그인 성공 시 역할에 따라 적절한 대시보드로 이동
  - ADMIN, PM, PMO → PM 대시보드
  - MEMBER → 실무자 대시보드
- `remember me` 옵션으로 이메일 자동 저장 (로컬 스토리지)

```
│              │ ├──────────────────────────────────────────────────────┤ │
│              │ │▶ 3. 테스트 단계     │  -   │대기  │░░░░░│10/01 │11/30 │    │
│              │ └──────────────────────────────────────────────────────┘ │
└──────────────┴──────────────────────────────────────────────────────────┘
```

**트리 표현 규칙**
- `▼` : 펼쳐진 상위 Task (클릭 시 접힘)
- `▶` : 접힌 상위 Task (클릭 시 펼쳐짐)
- 들여쓰기 2칸 단위로 하위 Task 표현
- 상위 Task의 진행률은 직속 하위 Task 진행률의 단순 평균 (읽기 전용, 자동 계산)
- D-day: 양수 = 마감 초과 (빨강), 0 = 당일 (주황), 음수 = D-N일 남음 (정상)

### 6.2 라우터 가드 (Navigation Guard)

```typescript
// router/index.ts

router.beforeEach(async (to, from, next) => {
  const authStore = useAuthStore()
  const isLoggedIn = authStore.isLoggedIn
  const userRole = authStore.userRole

  // 1. 로그인 필요 여부 체크
  if (to.meta.requiresAuth !== false && !isLoggedIn) {
    next({ name: 'login', query: { redirect: to.fullPath } })
    return
  }

  // 2. 이미 로그인된 상태에서 로그인 페이지 접근 시
  if (to.name === 'login' && isLoggedIn) {
    next({ name: 'home' })
    return
  }

  // 3. 역할 기반 접근 제어
  const requiredRoles = to.meta.roles as string[] | undefined
  if (requiredRoles && !requiredRoles.includes(userRole)) {
    next({ name: 'forbidden' })
    return
  }

  next()
})
```

```typescript
    title?: string                  // 페이지 제목 (브라우저 탭)
```
